# RentGram — Telegram-объявления → структурированный поиск

[English README](README.md) · [Открыть демо](https://rent-gram.netlify.app/)

**Задача.** В Telegram объявления о недвижимости разбросаны по каналам: условия, валюта, период аренды и характеристики написаны свободным текстом. Обычный поиск плохо отличает цену от расстояния до моря, продажу от аренды и месячную аренду от посуточной.

**Решение.** Python/Telethon получает сообщения, SQLite хранит состояние обработки и помогает избегать дублей, локальная LLM (Ollama) извлекает структуру, React показывает фильтруемую ленту. Подготовленный публичный набор полностью **вымышленный**; доступ к Telegram, API-ключи и установка модели для просмотра демо не нужны.

**Мой вклад.** Спроектировала процесс, поля результата и проверки, собирала и исправляла систему с AI coding assistant, тестировала крайние случаи и интерфейс. Это не заявление о самостоятельной экспертной разработке всех компонентов вручную.

**Проверки.** `cd frontend && npm ci && npm test && npm run build`. Для извлечения: `pip install -r requirements.txt pytest` и `python -m pytest -q tests/test_price_validation.py`. В тестах проверяются RUB/GEL/USD/AMD, неизвестная валюта, предложения продажи, период оплаты, депозит и повторные записи.

**Ограничения.** Результат зависит от качества LLM-разбора; недоказанные курсы не следует показывать как подтверждённые. На публичной странице используются только синтетические примеры, не актуальная база объявлений. Оригинальные старые выгрузки могли сохраняться в истории Git.
